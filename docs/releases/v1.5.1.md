# v1.5.1 Release (2026-08-27)

## Bug Fixes & Improvements
* **Fail-Fast Error Handling in `configure_gcp_endpoints`:**
  * Added `set -e` to `actions/configure_gcp_endpoints/deployment_script.sh` to guarantee immediate step failure on any command error.
  * Explicitly check exit code of `gcloud endpoints services deploy`, outputting actionable error annotations to GitHub Actions if deployment fails.
  * Fixed regex / bracket parsing bug for `CONFIG_ID` to prevent service account error strings (e.g., `[github-actions-deploy@...]`) from being mistakenly parsed as configuration IDs and masking deployment failures.
