# v1.5.2 Release (2026-08-31)

## Updates & Improvements
* **Decouple WIF Deployer and ESPv2 Gateway Service Accounts in `openapi_update`:**
  * Added optional `deployer_service_account` input to `.github/workflows/openapi_update.yml` matching the pattern established in `gcp_function_deployment.yml`.
  * Clarified the role of `default_service_account` as the ESPv2 gateway runtime service account receiving `roles/run.invoker` or `roles/cloudfunctions.invoker` permissions on the backend service.
  * Updated `GCloud SDK Setup` to authenticate using `${{ inputs.deployer_service_account || inputs.default_service_account }}` to support keyless Workload Identity Federation (WIF) deployments without disrupting ESPv2 proxy permissions.
  * Maintained 100% backward compatibility: if `deployer_service_account` is omitted, the workflow defaults to using `default_service_account` for runner authentication.
