# v1.5.0 Release (2026-08-18)

## Updates
* **GCP Workload Identity Federation (WIF) Support:**
  * Added `workload_identity_provider` and `service_account` inputs to `actions/setup_gcloud`, `cloud_run_api_deployment.yml`, `gcp_function_deployment.yml`, and `openapi_update.yml`.
  * Enables keyless OIDC authentication directly from GitHub Actions runners into Google Cloud Platform without storing static service account JSON keys.
  * Maintained 100% backward compatibility: existing workflows that pass `gcp_credentials` continue to function seamlessly.
